First, we need to import the dataset from the scikit-learn library

from sklearn import datasets
import pandas as pd
import numpy as np

data_iris = datasets.load_iris() #get data

The dataset contains some keys, which we can use to access specific data.

For example, if we want to get the data about the length and width of iris flowers, we can specify iris["data"]

Next step is converting the dataset to pandas dataframe

df_iris = pd.DataFrame(

Create a categorical column and insert names os species in it.

species = []

for i in range(len(df_iris["target"])):
    if df_iris["target"][i] == 0:
        species.append("setosa")
    elif df_iris["target"][i] == 1:
        species.append("versicolor")
    else:
        species.append("virginica")

df_iris["species"] = species

Performing a classification model using sklearn library

from sklearn.model_selection import train_test_split

#design matrix
X = df_iris.drop(["target", "species"], axis = 1)

#converting a numpy array petal length petal width
X = X.to_numpy()[:, (2,3)]
y = df_iris["target"]

#split  into train and test set
X_train, X_test, y_train, y_test = train_test_split(X,y, test_size = 0.5, random_state=42)

Now we need to define a logistic model

from sklearn.linear_model import LogisticRegression

log_reg = LogisticRegression()
log_reg.fit(X_train, y_train)
